📖 Пошаговый гайд: получение бесплатного ключа Groq (1 минута)
  1. Перейдите в консоль: console.groq.com/keys ↗
  2. Войдите в 1 клик через аккаунт Google или GitHub.
  3. Нажмите кнопку Create API Key.
  4. В поле Name введите OLEG и нажмите Create.
  5. Скопируйте ключ (начинается на gsk_...) и вставьте в поле выше.
⚡ 100% бесплатно (до 2 000 команд в день). Обеспечивает кристально чистое распознавание речи без занятия места на вашем ПК!
