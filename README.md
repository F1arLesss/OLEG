# 🤖 О.Л.Е.Г. — Ответственный Ликвидатор Ежедневного Геморроя

> Умный, быстрый и живой ассистент для Windows, который вызывается по **Ctrl + Space**, слушает голос, управляет приложениями на компе и отвечает на любые вопросы.

Олег постоянно на чеку в фоне: он понимает, когда к нему обращаются по имени, и может выполнить команду полностью по голосу — даже без прикосновения к клавиатуре. 

Нажал хоткей — строка вылетела поверх любого окна или игры. Сказал голосом или написал команду — Олег моментально всё сделал.

---

## 🔥 Что Олег умеет

- 🎙️ **Быстрый голосовой ввод:** Распознавание через Groq Whisper Large v3 Turbo с откликом ~150 мс. Отлично понимает русскую и английскую речь и не занимает место на диске.
- 🔊 **Живая нейроозвучка:** Отвечает естественными голосами Microsoft Neural (Дмитрий или Светлана) с грамотной разговорной интонацией и настраиваемым темпом речи.
- ⚡ **Калькулятор и конвертер на лету:** Вбиваешь `250 * 1.15`, `30% от 4500` или `100 eur в rub` — результат появляется мгновенно, без задержек и без траты токенов нейросети.
- 🚀 **Запуск приложений без задержек:** «Открой спотифай», «запусти дискорд», «вруби стим» — находит программы и игры по названию или сленгу и открывает их моментально.
- 🎵 **Управление Spotify:** Поиск треков, переключение музыки, пауза и плейлисты голосом или текстом.
- 🎛️ **Управление звуком и окнами:** Может убавить звук в конкретной игре или браузере, отрегулировать громкость системы, свернуть или закрыть окно.
- 🧠 **Долгосрочная память:** Запоминает контекст диалога и важные факты о вас, чтобы не переспрашивать одно и то же.
- 📋 **История буфера обмена:** Хранит скопированные фрагменты и позволяет быстро найти и вставить нужный текст.
- ⚙️ **Понятные настройки:** Никакой ручной возни с конфигами через блокнот — прямо в приложении есть удобное меню со ссылками на получение ключей, скрытием секретных данных за точками и выбором голоса.

## 🛠 Быстрый запуск

### Что нужно перед стартом:
1. **Windows 10 / 11**
2. **Python 3.10+** (не забудьте поставить галочку *Add Python to PATH* при установке)
3. **Node.js 18+**

### 1. Клонируем проект
```powershell
git clone https://github.com/your-username/OLEG.git
cd OLEG
```

### 2. Ставим бэкенд (Python)
```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd ..
```

### 3. Ставим интерфейс (Electron)
```powershell
cd electron
npm install
cd ..
```

### 4. Погнали!
Просто запустите скрипт:
```powershell
.\start.bat
```

> **Первый запуск:** При первом старте прямо в строке Олега появится пошаговый мастер настройки — он наглядно подскажет, куда вставить ключи. Занимает ровно пару минут.

Для полной остановки всех процессов:
```powershell
.\stop.bat
```

## 🔑 Где взять бесплатные ключи

Олег может работать на полностью бесплатных ключах:

1. **Groq API (для быстрого слуха Whisper):**
   - Идём на [console.groq.com/keys](https://console.groq.com/keys)
   - Жмём логин через Google/GitHub и создаём ключ `gsk_...`
   - Бесплатного лимита хватает с головой на тысячи голосовых запросов в день.

2. **Google Gemini API (основной мозг):**
   - Заходим в [Google AI Studio](https://aistudio.google.com/)
   - Жмём *Get API Key* и копируем ключ `AIzaSy...`
   - В настройках Олега ставим модель `gemini-2.5-flash` и Base URL `https://generativelanguage.googleapis.com/v1beta/openai/`. Бесплатный тариф работает отлично.

3. **OpenRouter (если хотите Claude, GPT-4o или Llama):**
   - Ключ берётся на [openrouter.ai/keys](https://openrouter.ai/keys).

4. **Spotify Web API (опционально, если нужно управление музыкой):**
   - Создаём приложение на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard).
   - Забираем `Client ID` и `Client Secret`.

Все ключи можно вбить прямо в интерфейсе (иконка ⚙️ в строке) — они сразу сохранятся в файл `backend/.env`.

## ⌨️ Управление

| Клавиши | Что делает |
|---|---|
| `Ctrl + Space` | Показать или спрятать Олега из любого места в системе |
| `Enter` | Отправить запрос или выполнить команду |
| `Escape` | Закрыть меню настроек или свернуть строку |
| `↑` / `↓` | Листать историю предыдущих команд |
| Клик по ⚙️ | Открыть или закрыть панель настроек |

## 📂 Как устроен проект

```
OLEG/
├── start.bat               # Запуск всего в 1 клик (бэкенд + окно)
├── stop.bat                # Чистая остановка процессов
├── .gitignore              # Ваши ключи и история буфера никогда не улетят в репозиторий
├── electron/               # Фронтенд на Electron
│   ├── index.html          # Разметка оверлея и настроек
│   ├── style.css           # Тёмная стеклянная тема и физика анимаций
│   ├── renderer.js         # Запись звука, хоткеи, живой UI
│   └── main.js             # Системный трей и глобальный Ctrl+Space
└── backend/                # Бэкенд на FastAPI
    ├── .env.example        # Образец конфига
    ├── main.py             # Серверные ручки и веб-сокеты
    ├── brain.py            # Общение с нейросетями и распознавание речи
    ├── tts_engine.py       # Голосовой движок Edge-TTS
    ├── sound_manager.py    # Воспроизведение звуков и точные тайминги MCI
    └── tools.py            # Автоматизация Windows, реестр, Spotify
```
